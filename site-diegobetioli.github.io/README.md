# Portfolio · Diego Betioli

Site público: **https://diegobetioli.github.io/**

## Como editar (sem programação)

O site é editado por um formulário no **Pages CMS**, um editor gratuito ligado a este repositório.

### Primeira vez (uma vez só)

1. Acesse **https://app.pagescms.org** e clique em **Sign in with GitHub**.
2. Autorize o acesso e, quando pedir, instale o Pages CMS no repositório **diegobetioli.github.io**.
3. Escolha o repositório **diegobetioli.github.io** na lista.

### Adicionar um conteúdo

1. Em **app.pagescms.org**, abra **Meu portfolio**.
2. Em **Conteúdos**, clique em **Add an entry** (adicionar item).
3. Preencha **Título** e **Categoria**.
4. Informe o **Link do conteúdo** *ou* envie um **Arquivo** (PDF, Word, imagem ou vídeo).
5. Se quiser, preencha onde foi publicado, data, resumo e palavras-chave.
6. Clique em **Save** (salvar).

O site é atualizado sozinho em 1 a 2 minutos. Se não aparecer, atualize a página do navegador.

### Editar ou remover

Abra **Meu portfolio**, clique no conteúdo que quer mudar, altere e salve. Para remover, use o ícone de lixeira ao lado do item e salve.

### Mudar o topo da página

Em **Meu portfolio**, role até **Perfil (topo da página)** para trocar nome, título, apresentação e links.

## Arquivos do site (para referência técnica)

| Arquivo | Para que serve |
| --- | --- |
| `index.html` | A página |
| `conteudos.json` | Perfil e lista de conteúdos (é o que o editor altera) |
| `arquivos/` | PDFs, documentos e imagens enviados pelo editor |
| `.pages.yml` | Configuração do formulário do Pages CMS |
